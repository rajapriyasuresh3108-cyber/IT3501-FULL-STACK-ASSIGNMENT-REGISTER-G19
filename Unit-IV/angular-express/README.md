# Unit IV – Task 4.5
## Angular and Express REST API Integration

### Objective
To develop an Angular student registration interface
that communicates with an Express REST API.

### Technologies Used
- Angular
- TypeScript
- Node.js
- Express.js
- REST API
- HTML and CSS

### API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | /api/students | Retrieve students |
| POST | /api/students | Add student |

### Features
- Student registration form
- Display student records
- Angular HTTP Client integration
- Loading state
- Success and error messages
- Form validation
- CORS configuration

### Run Backend
cd backend
npm install
node server.js

### Run Frontend
cd frontend
npm install
npm start

### URLs
Frontend: http://localhost:4200
Backend: http://localhost:5001
